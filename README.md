# Привет, я Пётр

Пишу приложения для себя и близких: когда штатная программа раздражает, проще сделать свою.
Санкт-Петербург. Python и Kotlin, немного JavaScript и PowerShell.

## Проекты

| Проект | Что это | Стек |
|---|---|---|
| [PassVault](https://github.com/Keavors/PassVault) | Офлайн-хранилище и генератор паролей для Windows. Argon2id + AES-256-GCM, четыре слоя резервных копий, слияние с разбором расхождений | Python, tkinter |
| [PassVaultAndroid](https://github.com/Keavors/PassVaultAndroid) | Парное приложение для Android с тем же форматом файла и такой же логикой слияния | Kotlin |
| [PdfReader](https://github.com/Keavors/PdfReader) | Читалка PDF без рекламы и лишних разрешений: недавние файлы, оглавление, режим чтения | Kotlin |

Ещё в работе и в личных репозиториях: галерея для Android вместо штатной, органайзер задач
с голосовым вводом, раздельная маршрутизация для Windows, приложение для тактических
презентаций футбольной команды, браузерная игра на React.

## Как я делаю

- Сначала тесты на опасные места: запись на диск, формат файла, совместимость между устройствами.
- README на русском, с объяснением, почему решение именно такое.
- Ничего лишнего в профиль пользователя и в облако: данные лежат там, где их видно.
