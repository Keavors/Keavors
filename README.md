## About me

I make small, opinionated tools for myself and the people around me: when a stock app gets in the way, it is usually faster to build my own.

**Honest disclaimer:** most of this is vibecoding. I design the product, write the specs, argue with the AI about every decision, test on real devices and ship. I rarely type the code myself. What I care about is that the thing works, survives a power cut, and explains itself in the README.

- 🔐 Offline first. No clouds, no accounts, data stays where you can see it.
- 🧪 Tests on the dangerous parts: writing to disk, file formats, cross-device compatibility.
- 📝 Every project has a README that says *why*, not just *what*.
